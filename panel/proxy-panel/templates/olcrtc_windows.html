olcRTC на Windows

Консольный клиент olcRTC
← Назад к гайду

1. Скачайте клиент

Скачайте консольный SOCKS5-клиент olcRTC для Windows:

⬇ Скачать olcrtc-windows-amd64.exe

Размер: ~32 MB

2. Создайте start-olcrtc.bat

Создайте в той же папке файл start-olcrtc.bat со следующим содержимым (замените свои параметры):

@echo off
chcp 65001 >nul
setlocal

REM === НАСТРОЙКИ (замените на свои) ===
set CARRIER=telemost
set ROOM_ID=your_room_id
set CLIENT_ID=your_client_id
set KEY_HEX=your_64_char_hex_key
set SOCKS_PORT=10808
set SOCKS_USER=your_socks_user
set SOCKS_PASS=your_socks_pass
set CLAIMS_USER=your_claims_user
set CLAIMS_PASS=your_claims_pass
REM ====================================

olcrtc-windows-amd64.exe ^
  -carrier "%CARRIER%" ^
  -room-id "%ROOM_ID%" ^
  -client-id "%CLIENT_ID%" ^
  -key-hex "%KEY_HEX%" ^
  -socks-port %SOCKS_PORT% ^
  -socks-user "%SOCKS_USER%" ^
  -socks-pass "%SOCKS_PASS%" ^
  -claims-user "%CLAIMS_USER%" ^
  -claims-pass "%CLAIMS_PASS%"

pause

Параметры claims-user и claims-pass можно найти в JSON/YAML конфигурации olcRTC, которую вы скачали из панели.

3. Запустите

Запустите start-olcrtc.bat. После успешного подключения вы увидите сообщение:

session opened

После этого настройте программу (браузер, приложение) на использование SOCKS5 прокси:

  • Адрес: 127.0.0.1
  • Порт: 10808 (или тот, который вы указали в SOCKS_PORT)
  • Авторизация: ваш SOCKS_USER / SOCKS_PASS
