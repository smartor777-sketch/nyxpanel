# Rules

Базовые правила работы с проектом.

- **Никогда не выполнять деплой на prod-сервер (`2.27.20.211` → prod) без явного подтверждения.**
- **Никогда не перезапускать продакшн-сервисы (hy2, xray, caddy, olcrtc, awg, mieru) без явного подтверждения.**
- **Никогда не изменять продакшн-конфиги в `/etc/` на сервере без явного подтверждения.**
- **Dev-сервер (`2.27.20.211`) — полигон. Можно ломать, переустанавливать, перезапускать. Но уточнять у пользователя.**
- Локальные изменения в `server/` и `config/` делать можно без разрешения.
- При изменениях кода — сначала проверяй синтаксис (`bash -n`, `python -m py_compile`, `go build`, `node --check`).
- Пароли и ключи из `.env` никогда не коммитить и не показывать в логах.
- Новые скрипты должны быть совместимы с Bash (Ubuntu 22.04+).
- Изменения в `proxy_manager.sh` должны сохранять обратную совместимость CLI-интерфейса.
