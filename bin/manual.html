1. Getting Started

NYX Panel provides access to proxy and VPN configurations for the following protocols:

VLESS+XHTTP+REALITY
Proxy Fast, modern proxy protocol
Hysteria 2
Proxy High-speed UDP-based proxy
NaiveProxy
Proxy Chrome-based proxy for stability
AmneziaWG
VPN Hardened WireGuard VPN
Mieru
Proxy Lightweight proxy protocol
olcRTC
Proxy WebRTC-based — mobile only
Trojan
Proxy TLS-disguised proxy protocol

Each configuration is available in three formats:

  • Config file — download the configuration file (Config button)
  • QR code — scan with your phone app (QR button)
  • Subscription link — copy the URL and paste into your app; it will auto-load settings. Click "Copy URL" to copy the subscription link.

2. Protocol Usage

olcRTC

Designed exclusively for mobile networks (4G/5G). Wi-Fi must be turned off for this protocol to work properly.

For exceptional cases where other protocols do not work, you can use the OlcboxME Windows application or the console utility.

VLESS+XHTTP+REALITY

This is the primary target for DPI blocking. It may sometimes fail to connect or hang. If you experience issues, try switching to another protocol.

Other protocols

Hysteria 2, NaiveProxy, AmneziaWG, Mieru, and Trojan work over standard internet connections (Wi-Fi, Ethernet).

Trojan

Disguises traffic as regular HTTPS traffic, making it difficult to detect. Works over TLS, providing reliable censorship bypass.
