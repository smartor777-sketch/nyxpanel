1. Общие сведения про NYX панель

NYX панель даёт доступ к конфигурации прокси и VPN (AmneziaWG - VPN, остальные - прокси) следующих протоколов:

VLESS+XHTTP+REALITY
Hysteria 2
NaiveProxy
AmneziaWG
Mieru
olcRTC

Конфигурации есть  трёх видов: 
1) файл с настройками (кнопка Config) 
2) QR-код, его можно сканировать в приложении (кнопка QR) 
3) Универсальная ссылка (Subscription), копируется по кнопке "Сopy URL". 
Ссылка копируется в буфер обмена и вставляется в приложение, и приложение само загружает настройки. Работает не везде :)

2. Особенности использования протоколов

Протокол olcRTC предназначен для работы исключительно в мобильной сети (без Wi-Fi, отключите его).
Остальные протоколы работают в проводных провайдерах (когда у вас интернет подключен через Wi-Fi).

Важно: протокол VLESS - главная мишень для РКН. Может иногда не подключаться или "висеть".
